## Lambert function W(x) :

   - The Lambert W function, also known as the product logarithm, is a set of functions defined as the inverse relation of the function f(W) = W * e^W, where e is the base of the natural logarithm. In other words, if y = W(x), then x = W(x) * e^(W(x)).
    
   - For now it is only a graph , but later on we will make the W(x) solver for any x value. 
    
   - The Lambert W function intrests us because it has applications in various fields, including combinatorics, physics, and computer science. It is particularly useful in solving equations involving exponentials and logarithms.
